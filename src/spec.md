# Specification

## Summary
**Goal:** Fix the Create Question dialog visibility issues and make question text optional for image-only questions.

**Planned changes:**
- Change Create Question dialog background from dark/transparent overlay to solid white background
- Remove asterisk (*) from Question Text field label and make the field optional
- Ensure all four option input fields (A, B, C, D) are fully visible with proper spacing

**User-visible outcome:** Users can clearly read and interact with the Create Question dialog on a white background, and can create image-only questions without entering question text.
